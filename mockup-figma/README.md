# EDM Task Management — Mockup for Figma

21 screens (17 web + 4 field app), EDM colours.

- `svg/` — import into Figma: drag the files onto the canvas. Text, shapes and colours stay editable (font: Roboto, built into Figma).
- `png/` — images at 2x, for quick viewing or slides.

Screen codes: W01–W17 = web (dispatcher, Call Center, NOC, team manager, admin), M01–M04 = field staff app.
The app screens M05–M10 are not designed yet.
